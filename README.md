# Smart Spaces Challenge
A DCoE Transition Year learning project for building a mobile game using specification-driven
development.
## Project goals
- Build one mobile-friendly app incrementally.
- Learn Git, specifications, coding, testing and release practices.
- Support a guided Smart Spaces path and original student ideas through one common framework.
- Connect one feature to Electronics, AIS or Commerce.
## Current checkpoint
Expo TypeScript application bootstrapped in `mobile/` and verified using the supported development
routes. Smart Spaces screens and game logic have not yet been added.
## Repository structure
- `docs/` - student, facilitator and architecture material
- `specs/` - phase specifications and acceptance criteria
