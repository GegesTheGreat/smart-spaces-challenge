# Common Smart Spaces Framework
## Principle
Students may follow Smart Spaces Challenge or adapt the theme, but every app uses the same supported
framework and phase gates.
## Required framework areas
1. Expo Router navigation
2. Reusable screen and button components
3. Shared theme
4. Scene model
5. Central game state and round flow
6. Configurable score engine
7. Event engine
8. One DCoE workstream feature interface
9. Local settings service
10. Local leaderboard service
11. Common tests and release checklist
## Phase 0 implementation boundary
Phase 0 implements navigation, placeholders and shared presentation components only. The remaining
framework areas are documented but are added incrementally in later phases.
## Own-idea rule
An original student idea may change the app name, story, scenes, labels, visuals, controls and
feature content. It must not replace the agreed navigation, engine interfaces, test gates or release
process without facilitator approval.
